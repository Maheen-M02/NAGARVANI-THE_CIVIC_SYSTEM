## 🌟 Overview

**Nagarvani - The Civic System** is an innovative platform designed to bridge the gap between citizens and civic authorities. It provides efficient tools for reporting civic issues, monitoring resolution status, and fostering community engagement for transparent and accountable urban management.

---

## 🚀 Features

- 📝 **Easy Issue Reporting**  
  Log civic concerns in just a few clicks about roads, lighting, waste management, and more.

- 🔔 **Real-Time Notifications**  
  Stay updated with instant alerts on issue progress or requests for additional info.

- 📈 **Dashboard & Analytics**  
  Powerful insights for citizens and authorities to monitor trends and resolution speeds.

- 🗺️ **Location-Based Tracking**  
  Visualize issues on an interactive city map for faster response.

- 👩‍💻 **Admin Panel**  
  Authorized staff can manage reports, assign tasks, and close tickets with accountability.

## ⚡ Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Maheen-M02/NAGARVANI-THE_CIVIC_SYSTEM.git
cd NAGARVANI-THE_CIVIC_SYSTEM
```

### 2. Set Up Environment

_Backend:_

```bash
cd backend
# Install dependencies
npm install
# Or with pip if using Python
# pip install -r requirements.txt
```

_Frontend:_

```bash
cd frontend
npm install
```

### 3. Run the App

_Backend:_
```bash
npm start
# or
# uvicorn main:app --reload
```
_Frontend:_
```bash
npm start
```
> The app will be available at `http://localhost:3000`
